nara-detector - 공공조달 제안 업무 자동화 AI Agent

2026.07 - 진행 중 · MVP 검증 완료
개인 프로젝트 · AI Agent / Backend

프로젝트 개요

나라장터 입찰공고를 자동 수집하고, 공고·첨부 문서를 분석해 사내 솔루션과의 참여 적합성을 판정합니다. 이후 제안서 초안 생성·검증·담당자 승인·DOCX 이메일 발송까지 연결한 하이브리드 AI Agent 시스템입니다.

핵심 구현

  • 공고·첨부 수집: 나라장터 API 수집, 조건 필터링, 첨부파일 다운로드 및 HWP → PDF 변환
  • 독립 2경로 문서 추출: 텍스트 파서와 Ollama 기반 Vision LLM이 독립적으로 필드를 추출하고 결과를 대조
  • 교차검증 및 예외 격리: 문서 추출값과 API 메타데이터를 교차검증하며, 불일치·실패 건은 needs_review로 분기
  • 하이브리드 모델 전략: 대량 문서 처리는 로컬 LLM, 제안서 생성·사실성 검증은 대형 API 모델로 분리 설계
  • 코드 기반 검증: 예산·마감일·필수 항목 등 결정적 규칙은 LLM이 아닌 코드로 검증하고 LLM 사실성 검증을 추가 적용
  • Human-in-the-loop: 담당자 승인 전 발송을 차단하고, 발송 직전 서버가 승인 상태를 재검증

처리 흐름

1단계: 공고·문서 수집
나라장터 API에서 공고와 첨부파일을 수집하고, HWP 문서를 PDF로 변환합니다.
↓
2단계: 이중 추출 및 교차검증
텍스트 파서와 로컬 Vision LLM이 독립적으로 필드를 추출합니다. 두 결과와 API 메타데이터를 대조해 불일치 건을 검토 대상으로 분기합니다.
↓
3단계: 매칭·제안서 생성 및 검증
공고와 솔루션을 매칭해 제안서 초안을 생성하고, 규칙 기반 검증과 LLM 사실성 검증을 적용합니다.
↓
4단계: 담당자 승인·발송
담당자 승인 후에만 DOCX를 생성하며, 서버가 승인 상태를 재검증한 뒤 이메일을 발송합니다.

SUMMARIX - AI 기반 경제뉴스 분석 웹서비스

2025.09 - 2025.10
기획 총괄 · AI 챗봇 개발

프로젝트 개요

경제 뉴스를 효율적으로 분석하고 핵심 이슈와 감성 흐름을 한눈에 파악할 수 있는 AI 기반 플랫폼입니다.
프로젝트 기획 총괄과 GPT-5와 RAG 기술을 결합하여 실시간 경제 질의응답이 가능한 챗봇을 구현했습니다.

주요 담당 업무 (5인 프로젝트)

  • 전체 시스템 아키텍처 설계 및 FastAPI 기반 백엔드 서버 구축
  • GPT-5 Function Calling을 활용한 AI 챗봇 개발 (실시간 경제지표 조회, RAG 기반 문서 검색)
  • MongoDB Atlas 연동으로 최신 뉴스 데이터 실시간 수집 및 관리
  • ECOS(한국은행), FRED(미국 연준), yFinance API 통합으로 경제지표 자동 조회 시스템 구현
  • CLOVA STT와 Google Cloud TTS 연동으로 음성 대화 기능 구현
  • Vector Store 기반 RAG 시스템 구축 및 자동 문서 갱신 파이프라인 개발
  • 프로젝트 로드맵에 따른 역할 분담 및 일정 조율, 최종 결과물 발표 준비

챗봇 시스템 아키텍처

1단계: 데이터 수집
① APScheduler가 10분 간격으로 다양한 소스에서 경제 뉴스 및 지표 데이터를 자동 수집.
② Naver 뉴스 크롤링을 통해 최신 경제 뉴스를 스크래핑, 한국은행 ECOS API로 국내 경제지표를 수집.
③ 미국 경제지표는 FRED API를 통해 연방기금금리를 조회, yFinance API로 지표, 환율 등 실시간 시세 데이터를 수집.
↓
2단계: 데이터 저장
① 수집된 최신 기사 데이터는 MongoDB Atlas의 chatbot_rag 데이터베이스에 중앙 집중식으로 저장.
② 뉴스 기사는 제목, URL, 발행일시와 함께 저장되며, 내림차순 인덱스가 적용되어 최신 데이터 조회 성능을 최적화.
↓
3단계: AI 챗봇 엔진
① GPT-5 모델을 활용한 Function Calling 메커니즘이 사용자 질의를 분석하여 적절한 함수를 자동 선택.
② RAG 시스템은 폴더를 실시간 감시하여 파일 변경을 감지하면 자동으로 OpenAI API로 업로드하고, 이를 Vector Store에 연결.
↓
4단계: 웹 서비스 통합
① FastAPI 서버(포트 8000)가 /chat, /api/stt, /api/tts 엔드포인트를 제공.
② Spring Boot 서버(포트 8081)의 ChatController.java가 클라이언트 요청을 FastAPI로 전달하고 응답을 반환.
③ STT 기능은 CLOVA API를 사용하며, 업로드된 오디오 파일을 ffmpeg로 WAV로 변환한 후 텍스트로 변환.
④ TTS 기능은 Google Cloud TTS API로 텍스트를 MP3, WAV 형식의 음성으로 합성.
↓
5단계: 사용자 인터페이스
① Spring Boot와 Thymeleaf 템플릿 엔진이 동적 웹페이지를 렌더링.
② 사용자는 챗봇 인터페이스를 통해 텍스트 또는 음성으로 질문하고, AI가 실시간 데이터를 기반으로 답변.

핵심 기술 구현

  • Function Calling 구조: get_latest_news(), get_market(), search_docs() 등 함수를 통해 실시간 데이터 조회
  • RAG 시스템: watcher.py를 통한 문서 자동 감시 및 Vector Store 실시간 갱신
  • API 엔드포인트: /chat, /tts, /stt, /rag/docs 등 REST API 설계

프로젝트 성과

  • 10분 간격 자동 수집으로 실시간 경제 데이터 통합 시스템 구축 (ECOS, FRED, yFinance 3개 API 연동)
  • RAG Vector Store 기반 문서 검색으로 질의응답 정확도 향상 및 환각 현상 감소
  • CLOVA STT + Google TTS 연동으로 텍스트/음성 멀티모달 인터페이스 구현
  • FastAPI + Spring Boot 이중 서버 아키텍처 설계 및 5인 팀 프로젝트 총괄

프로젝트 개요

SUMMARIX에서 구현한 GPT API 기반 챗봇을 독립적으로 고도화한 프로젝트입니다. 외부 모델 API 의존도를 낮추기 위해 Ollama 기반 로컬 LLM을 적용하고, 경제 데이터 조회와 문서 검색을 연결한 AI 경제 분석 챗봇을 구현했습니다.

핵심 구현

  • 로컬 LLM: Ollama 기반 로컬 환경에서 LLM 추론 수행
  • 규칙 기반 Tool Routing: 사용자 질의를 뉴스·주가·환율·경제지표·문서 검색 작업으로 분류하고 적합한 도구 호출
  • FAISS 기반 RAG: 경제 관련 문서를 벡터화하고 관련 근거를 검색해 답변에 활용
  • 서비스·음성 통합: FastAPI와 Spring Boot를 연동하고 STT/TTS 기반 음성 질의·응답 지원
  • 배포: AWS EC2 환경에 웹서비스 배포

기술 스택

  • FastAPI · Spring Boot · Ollama · FAISS · MongoDB · AWS EC2
